# Liquid Neural Network для прогнозирования временных рядов

Реализация Liquid Time-Constant (LTC) сети на PyTorch для прогноза временного ряда. Учебный проект, 2 курс, Computer Science, КазНУ им. аль-Фараби.

## Что внутри

- `LiquidTimeConstantCell` — LTC-ячейка с обучаемой постоянной времени `tau` для каждого нейрона, шаги Эйлера внутри тика.
- `LiquidNeuralNetwork` — двухслойная сеть (32 и 16 нейронов) с LayerNorm, Dropout и линейной головой.
- Скользящее окно: по 40 прошлым точкам прогноз на 5 шагов вперёд.
- Обучение: AdamW, ReduceLROnPlateau, gradient clipping, early stopping.
- Сохранение и загрузка чекпоинта, графики результатов.

## Данные

Синтетический ряд: сумма трёх синусоид, слабый тренд и шум. Реальные данные не использовались.

## Результат

Test MSE около 0.018 (модель с 2 033 параметрами, 10 эпох). Графики: корреляция предсказаний с реальностью, кривые обучения, прогноз на тестовых точках.

## Запуск

```
pip install -r requirements.txt
```
Затем открой `LnnCorr.ipynb` в Jupyter или VS Code и выполни ячейки по порядку.
